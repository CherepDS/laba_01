## Описание проекта

Проект представляет собой консольную утилиту (`toolkit`) для выполнения базовых вычислений и конвертации различных единиц измерения. Утилита реализована на языке Python с использованием фреймворка **Typer** для построения интерфейса командной строки (CLI).

## Необходимые библиотеки

* ```pip install typer```
* ```pip install tomli-w```

Основные модули утилиты:
*   `calc` — простой калькулятор выражений.
*   `convert` — конвертер величин (температура, вес, длина).

## Функциональные возможности

1.  **Калькулятор (`toolkit calc`)**:
    *   Доступные операции: ``` * / + - // % ``` 
    *   Поддерживаются как целые, так и вещественные числа
    *   Поддержка унарных операторов (*-3--5=2*)
    *   Поддержка скобочных выражений, алгебраических приоритетов вычисления.
    *   Обработка ошибок ввода и синтаксических ошибок в выражении.


2.  **Конвертер (`toolkit convert`)**:
    *   Конвертация значений между различными единицами измерения
        ```
        # По умолчанию:
        mass = [kg, g]
        length = [km, m, cm, mm]
        temperature = [c, k, f]
        ```
    *   Обработка ошибок ввода.
    *   Форматированный вывод результата

## Примеры команд

#### Калькулятор (`calc`)
``` 
python -m toolkit calc --expr "2 + 2 * 2"
```
#### Конвертер (`convert`)

```
python -m toolkit convert --value 40 --from-unit f --to-unit c
```
#### Справки (`--help`)
```
python -m toolkit --help
python -m toolkit convert --help
python -m toolkit convert --help
```
## Дополнительный функционал

* Поддержка *//* и *%*, а также отрицательных операторов
* Точные вычисления с помощью *Decimal*, математическое округление до 3 знаков после запятой
* История успешных вычислений сохраянятется в *calc_history.json*
* Таблица конвертаций загружается из конфигурационного файла *pyproject.toml*
* Логика работы калькулятора основана на переводе выражения в *RPN*, затем вычисление стеком
